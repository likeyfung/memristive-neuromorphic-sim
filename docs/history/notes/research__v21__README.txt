# V21 — Conductance learning and complementary continuous state

V20 is preserved. V21 keeps 256 neurons, 12 dendritic compartments per neuron (8 basal, 3 tuft, 1 trunk), 8 allocated input contacts per compartment, 16 shared WaveTiles, 1,024 local recurrent edges and 256 interpopulation edges. This is a reduced engineering model, not a reconstruction of a particular biological cell.

Use Python with NumPy, SciPy, scikit-learn and Matplotlib. On this machine:

## Preserved scientific protocol

Train/calibrate → validate → freeze → fresh test. Conductance learning uses no labels or validation/test activity. A training-only scale floor is `max(0.02, 0.05 × median(nonzero training SD))`; N and W scales are fitted separately. This absolute floor is in normalized model units, not volts or noise specifications. There is no test clipping or retraining after seeing the test.

Each of three models receives ten preset trials, 24 readout-training streams and 12 independent validation streams. Every candidate has one local conductance-calibration step from 12 training streams. Validation selection combines finite-lag memory, nonlinear decoding, training participation ratio and an excess-rate penalty. The rate penalty uses a 20-ms spike-trace rate proxy measured on training only. Final selected settings receive larger, separate development sets: 48 training and 24 validation streams. Conductances are recalibrated from the first 12 new training streams. All readouts/weights/settings are frozen and hashed before the 48-stream test is generated. This is a modest local-learning/search budget, not convergence of an optimized learning algorithm.

The digital control is frozen separately before test generation. Its saved freeze timestamp documents this. Its evaluator consumes the same test file only after the physical benchmark finishes.

## What is learned and what produces the reservoir

Each allocated input contact has its own positive conductance multiplier and each recurrent edge its own positive magnitude. E/I sign remains determined by the presynaptic cell. Multiple presynaptic event lines can converge on the same existing contact; their event counts are summed before multiplication by that contact's conductance. Different weights then contribute to a shared dendritic filter and integration state. This preserves the earlier input contact topology.

An offline activity-dependent learning pass multiplies input conductances by `exp(0.4 × corr(contact preactivity, branch voltage))` and a bounded postsynaptic homeostatic factor. Recurrent magnitudes use lagged pre/post correlations, with an opposite update sign for inhibitory sources. Values are clipped to [0.2,2]. These are heterogeneous per-contact/per-edge updates based on training activity, not just one global trained weight. Initial weights are heterogeneous too. Allocated but disconnected contacts can receive the homeostatic update; they do not affect inference. A same-operating-point untrained heterogeneous control tests whether this particular learning rule helps.

Weights remain fixed during inference. The recurrent connectivity and synaptic/dendritic/soma states create reservoir dynamics; weights do not have to change every inference step for a reservoir to exist. Learning changes the dynamics the conductances implement. Only one offline local update is used here, not STDP, BPTT, on-chip learning circuitry or supervised recurrent optimization.

## Matched state comparison

Hybrid: complex I/Q oscillator, intrinsic damping, reciprocal phase-sensitive neighbor exchange, population-spike emission and heterogeneous local feedback.

Nonoscillatory control: same tile count, same two real states per tile, same neighbor edge magnitudes, input projection norm and feedback/detector paths. Intrinsic poles are −1/τ and −2/τ; neighbor exchange is symmetric diffusion. Both coordinates are driven via a fixed π/4 emission projection in BOTH models. The two different real decay poles avoid an identically undriven/redundant Q coordinate. The leaky operator has real negative eigenvalues. This matches state count/topology/interfaces, not exact eigenvalues or energy costs; removing oscillation necessarily changes dynamics.

Spike control: same recurrent neurons with wave state disabled. Each main model is independently calibrated. Separately, frozen-readout ablations change a single operating switch/law using the hybrid's settings and conductances. Direct N, W and N+W decoders are diagnostic information-access comparisons: W-only and combined readouts would require additional sensing/readout hardware and do not prove information reached the soma.

## Task and metrics

Synthetic independent two-channel binary symbols, 20-ms symbols, encoded into four Poisson event streams; active event rates vary independently by history. The readout reconstructs two channels at delays 0,20,…,100 ms and classifies current channel 0 × previous channel 1. This targets short temporal context, not EEG accuracy or cognition itself.

Memory is `sum max(0,R²)` across 12 held-out lag/channel targets. Raw sums and each lag score are retained because positive clipping is biased. This is a finite-lag decoding proxy, not mutual information, RAM bits or total memory capacity. PR is covariance participation ratio after training-style scale flooring, not a count of concepts or useful bits. Temporal samples within one history are correlated; confidence intervals bootstrap complete histories.

The digital task algorithm uses twelve exponential filters (two event-difference channels × six decay constants) plus 36 combinational cross-products and a trained linear readout. Its products are not recurrent stored state. This is a task algorithm control, not a digital replay of all neuron/circuit equations. Fixed time constants are not independently searched, so its tuning budget is smaller than the physical models'.

## Storage and energy

Weights stored in conductance still occupy physical storage. Analog voltages, currents and refractory timing are also state. The ASIC could avoid numerical load/update/store cycles for those variables by implementing their dynamics physically. This is different from eliminating all RAM or all memory.

`accounting.json` separates model-state equivalents, conductance-weight equivalents, readout coefficients, event-delay buffering and fixed-step logical updates. 8/16/32-bit equivalence is assumed precision, not demonstrated analog ENOB. Synaptic filters are aggregated per branch exactly only because contact kernels are identical and their linear contributions share the same local voltage dependence. A circuit with distinct contact time constants would require more state.

No measured SRAM/DRAM traffic, full-chip latency, supply power, energy or area exists here. Wave capacitors, transconductors, bias, routing, weight programming, learning traces, ADC/readout and retention/noise costs require circuit/device measurement. A direct conductance resistor consumes signal energy; transistor bias power cannot be inferred from its resistance alone. Digital processors, including digital neuromorphic chips, can retain local state in registers/on-chip SRAM rather than repeatedly access external DRAM.

## Circuit deliverables

`circuit/programmed_synapse.va`: behavioral programmed conductance with ideal retained state and a per-instance AMPA/NMDA contact filter. It is not a measured memristor model or tapeout-ready transistor design. WRITE samples CODE; inference holds WRITE low. Initial conductance can be instantiated separately for each synapse. The contact-filter module uses a frozen GWEIGHT parameter; connecting a programming cell to a shared branch filter requires current-summing/interface design.

`circuit/conductance_bench.cir`: actual ngspice fixed-resistor/RC test for 0.4,1.0,1.6 µS under identical input. It checks weighted response against analytical RC behavior. It does not compile the Verilog-A, test NVM programming or simulate the whole array.

Selected learned multipliers are exported as weight arrays and a JSON mapping after the benchmark; illustrative conductance scaling is 1 µS per normalized multiplier and MUST be calibrated to a PDK and pulse area.
