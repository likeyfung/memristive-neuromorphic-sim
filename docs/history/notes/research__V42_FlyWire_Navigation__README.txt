# V42-FlyWire Navigation Branch

A V42-derived **application benchmark**, not a replacement of the original V42 associative-memory package.

Run:
```bash
python src/run_benchmark.py
python src/plot42_fly.py
```

The branch deliberately reports where an optimized task-native digital method wins. Its hardware-efficiency plot is a conditional same-dynamics sensitivity calculation, not measured ASIC power.
