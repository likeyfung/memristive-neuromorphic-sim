# V23 — Learn neuronal selection before biological adaptation

V22 is preserved. All model dependencies are copied locally. This revision isolates a sequence of engineering milestones; it does not claim a cognitive model or fabricated silicon.

## Four functional loops, three principal timescales

1. **Long-term experience:** individual synaptic conductances G. Future updates need a slow learning rule, modulation and a programming mechanism.
2. **Fast computation:** presynaptic events → AMPA/NMDA filters → reduced dendritic compartments → soma → spikes, with sparse recurrent event paths.
3. **Mesoscopic state:** shared W generated by population emission and exchanged only through wave couplers during normal operation.
4. **Selection:** phase-sensitive feedback changes which neurons respond to the current probe. This is a feedback function, not necessarily a fourth independent timescale.

Each population retains its 16 distinct neurons and shared WaveTile; total 256 neurons, 16 WaveTiles. Recurrent topology, fixed thresholds, individual contact values, and pooled inhibition are retained. No task decoder receives W, I/Q, phase or amplitude. Behavioral output is the original fixed overlapping-ensemble spike difference.

## Stage 1: controlled-state capacity

Initialize W to ±0.05 exp(jπ/4) across all tiles at probe onset, clear neuronal state, and disable ongoing emission. The initialized waves then evolve with the original oscillation, decay and neighbor couplers. This deliberately artificial initial-condition intervention isolates the wave→neuron pathway. It is not natural history generation, a routed external spike input, or a circuit-validated wave-writing procedure. The context is supplied in W by the experimenter at this stage only.

Keep synaptic conductances and feedback gain fixed. Train 256 feedback phases with 24 host-side finite-difference updates. A neuron-local reward encourages signed context-dependent activity in the prescribed target ensemble; the readout does not change. All phases are perturbed together; local credit is a heuristic in a recurrent network, not an exact individual partial derivative or biological plasticity.

Training uses a new 8-trial history batch per update. Validate every four updates on 16 separate histories, choose the highest signed selection, and freeze before generating 64 fresh trials. Groups pair identical probes across contexts and contain two different probes. Success gate: validation signed selection >0.1 and correct-ensemble fraction ≥0.75. These are engineering criteria, not validated neuroscientific thresholds. One topology/training seed and a small synthetic task limit generalization.

Readout: S=(mean EA spikes − mean EB spikes)/(mean EA spikes + mean EB spikes + epsilon). Report mean(context×S), correct signs (ties count incorrect), activity, and bootstrap intervals over 16 independent four-trial groups. EA/EB each contain 128 neurons, with 64 overlapping. Positive mean selection does not imply an exclusive winner-take-all state.

## Stage 2: natural history

First evaluate transfer from the controlled-state model: input cue 0–60 ms, silent interval to 140 ms, then probe to 220 ms. Emission and coupling remain active. No wave sign or context is injected into W.

The separate `natural_training.py` run then trains feedback phase, feedback gain and per-neuron contact scaling, retaining heterogeneous relative contact values. It uses 32 host updates with fresh development seeds, its own validation histories and a second fresh test set. It never trains on the controlled-stage test set. Recurrent edge values remain fixed. Each update uses simultaneous random perturbations and a neuron-local reward; conductances stay frozen during testing.

Wave erase in natural trials is a one-time intervention at probe onset. Neuronal history remains and later activity can regenerate W. Therefore natural erase/FB-off are not expected to make every context difference vanish. The controlled-stage erase and FB-off tests have identical neuronal initial states and identical probes, so they are stronger isolation tests.

## Stage 3: proposed slow eligibility loop — gated

Do not activate adaptive conductances to obscure an unsuccessful natural-history stage. Once that stage passes, separately evaluate an experience loop such as:

- pre/post event traces x_j, y_i;
- eligibility e_ij accumulating local pre/post correlation (optionally dendritic dependence);
- dG_ij/dt = eta M(t)e_ij − lambda(G_ij−G0), with conductance bounds;
- optional bounded wave learning gate H_i(W), added as its own ablation.

This proposal is not implemented as biological adaptation in the present benchmark. M must come from a specified reward/teaching mechanism; access to a target label is not spontaneous cognition. Positive eligibility alone with a scalar reward may reinforce the wrong active ensemble unless exploration, depression and credit assignment are designed explicitly.

For future continual-learning tests, freeze the learning rule/hyperparameters before evaluation, but allow G to change from permitted feedback. Compare plasticity off, modulator shuffled, eligibility off, and wave learning gate off. Measure learning curves, retention, interference, reversal learning and programming activity. Frozen inference accuracy and online adaptation are distinct protocols.

## Field-source scope

The primary source stays spike-only. D/S taps inherited from V22 remain normalized capacitor charging-current components, not complete synaptic/ionic/morphological extracellular field estimates. Adding those sources is deferred until selection is solved.

## Storage and hardware scope

Weights and dynamical states are still storage even if implemented as conductances and voltages. There are 24,576 allocated input contacts and 1,280 recurrent edges: 25,856 conductance values, or 51,712 bytes at an assumed 16-bit digital weight representation. Allocated contact count is not the number of independent afferents; input masks and parallel contacts reduce effective independence.

A proposed eligibility value per allocated contact/edge adds 25,856 slow states, equivalent to 103,424 bytes at float32, BEFORE pre/post traces and modulation. Physical implementation might avoid RAM updates for those states, but would add device/capacitor area, leakage, write energy, mismatch and endurance requirements. Some inactive contacts may be pruned in a later design. The 16 complex W states are only 32 scalars (128 bytes at float32). Those small wave states cannot stand in for arbitrary individual synaptic eligibility.

No power, energy, latency or RAM-traffic advantage is measured here. Python runtime is host simulation cost, not analog-chip latency. Learning feedback phase/gain also requires programmable settings, beyond synaptic conductance storage. There is no Cadence/PDK or memristor-device validation in this revision.

## Reproduce

From this folder:

```
OPENBLAS_NUM_THREADS=1 /tmp/wave-v7-env/bin/python src/milestones.py
OPENBLAS_NUM_THREADS=1 /tmp/wave-v7-env/bin/python src/natural_training.py
MPLCONFIGDIR=/tmp/wave-v23-mpl OPENBLAS_NUM_THREADS=1 /tmp/wave-v7-env/bin/python src/report_v23.py
```

Every experiment creates a fresh timestamped directory. `latest.txt` identifies controlled-stage results; `natural_latest.txt` identifies natural-stage results. Supporting files inherited from V22, including `experiment.py`, are utilities for model construction/task generation; the V23 entry points are the commands above.

## Reference for the proposed learning rule

Gerstner et al. (2018), *Eligibility Traces and Plasticity on Behavioral Time Scales*, discusses local eligibility plus a third modulatory factor: https://www.frontiersin.org/journals/neural-circuits/articles/10.3389/fncir.2018.00053/full . This motivates a future test; it does not validate this chip, learning implementation or a claim about consciousness.
